## What is Markdown?

Markdown is a lightweight markup language that lets you format text using simple syntax.

### Text Formatting

You can make text **bold** or *italic*. You can also use ~~strikethrough~~.


## Tips for Using Grimoire

1. **Press Ctrl+E** to toggle between view and edit mode
2. **Press Ctrl+S** to save your changes
3. **Press Ctrl+F** to search across all notes
4. **Use folders** to organize notes by topic
5. **Link notes** to create connections between ideas
