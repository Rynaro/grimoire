# Example Notes Structure

This directory contains examples of how to organize your notes in Grimoire.

## Suggested Organization

### Personal Knowledge Base
```
notes/
├── inbox/              # Quick capture notes
├── projects/           # Project-specific notes
├── areas/              # Ongoing areas of responsibility
├── resources/          # Reference material
└── archives/           # Completed or old notes
```

### Daily Notes
```
notes/
├── daily/
│   ├── 2025-01/
│   │   ├── 2025-01-15.md
│   │   └── 2025-01-16.md
│   └── 2025-02/
├── weekly/
└── monthly/
```

### Subject-Based
```
notes/
├── programming/
│   ├── python/
│   ├── javascript/
│   └── algorithms/
├── books/
│   ├── currently-reading/
│   └── finished/
└── ideas/
```

## Example Note Templates

### Project Note
```markdown
# Project Name

Status: In Progress
Started: 2025-01-15
Tags: #project #work

## Overview
Brief description of the project.

## Goals
- [ ] Goal 1
- [ ] Goal 2

## Resources
- [[Related Document]]
- [External Link](https://example.com)

## Notes
Daily updates and thoughts...
```

### Meeting Note
```markdown
# Meeting: [Title] - 2025-01-15

Attendees: Person A, Person B
Duration: 1 hour

## Agenda
1. Topic 1
2. Topic 2

## Discussion
Notes from discussion...

## Action Items
- [ ] Task 1 - @PersonA
- [ ] Task 2 - @PersonB

## Next Meeting
Date: 2025-01-22
```

### Research Note
```markdown
# [Research Topic]

Source: [Where you found this]
Date: 2025-01-15
Tags: #research #topic

## Summary
Key points...

## Detailed Notes
...

## Related
- [[Other Research Note]]
- [[Project Name]]

## Questions
- Question 1?
- Question 2?
```

## Tips

1. **Use Folders**: Organize by topic or time
2. **Link Notes**: Create connections with [[Note Name]]
3. **Consistent Naming**: Use clear, descriptive names
4. **Date Format**: YYYY-MM-DD for easy sorting
5. **Tags**: Use #tags for cross-cutting themes
6. **Index Notes**: Create hub notes linking related topics

## Getting Started

Copy these examples to your notes directory and adapt them to your workflow!
