# Grimoire Example Notes

This directory contains example notes to help you get started with Grimoire.

## Structure

```
examples/notes/
├── Personal Notes.md
└── Projects/
    ├── Grimoire.md
    └── Ideas.md
```

## How to Use

### Option 1: Copy to your notes directory

```bash
cp -r examples/notes/* ~/.grimoire/
```

### Option 2: Run Grimoire with the examples directory

```bash
grimoire examples/notes
```

## What's Included

- **Personal Notes.md** - Example of a personal journal and note-taking
- **Projects/Grimoire.md** - Technical documentation example
- **Projects/Ideas.md** - Project planning and todo lists

## Features Demonstrated

- Folder organization
- Markdown formatting
- Todo lists
- Note linking with [[Note Name]]
- Headers and structure
- Lists and formatting

Feel free to modify and expand these examples to suit your needs!
