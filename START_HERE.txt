Welcome to Grimoire! 📖✨

A beautiful terminal-based note-taking app inspired by Apple Notes and Obsidian.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 QUICK START

1. Install dependencies:
   pip install -r requirements.txt

2. Launch Grimoire:
   python grimoire.py

   Or use the quick script:
   ./run.sh

3. Optional - Run in Docker:
   docker-compose build
   docker-compose run --rm grimoire

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⌨️  KEYBOARD SHORTCUTS

   Ctrl+N  →  Create new note
   Ctrl+E  →  Toggle Edit/View mode
   Ctrl+S  →  Save note
   Ctrl+D  →  Delete note
   Ctrl+F  →  Search notes
   F5      →  Refresh file tree
   Ctrl+Q  →  Quit

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ FEATURES

   ✓ Beautiful terminal UI
   ✓ Full markdown support
   ✓ Syntax-highlighted code blocks
   ✓ Wiki-style note linking [[like this]]
   ✓ Full-text search
   ✓ Folder organization
   ✓ Plain text storage (you own your data!)
   ✓ Fast & lightweight
   ✓ Docker support

💡 TIPS

   • Notes are stored in ~/grimoire-notes/ by default
   • Use folders: "projects/My Project" when creating notes
   • Link notes: [[Note Name]] or [[folder/Note Name]]
   • Press Tab to switch between sidebar and content area
   • All notes are plain markdown files - edit anywhere!
