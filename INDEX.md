## 📖 Quick Reference

### Installation Commands

```bash
# Local installation
pip install -r requirements.txt
python grimoire.py

# Quick run
./run.sh

# Verify installation
./verify.sh

# Docker
docker-compose build
docker-compose run --rm grimoire
```
