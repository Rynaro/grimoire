# Keyboard Shortcuts

This note contains all the keyboard shortcuts available in Grimoire.

## Navigation

| Key | Action |
|-----|--------|
| `j` or `↓` | Move selection down |
| `k` or `↑` | Move selection up |
| `h` or `←` | Switch to folders (future) |
| `l` or `→` | Switch to notes (future) |
| `Space` | Scroll down |
| `PgDn` | Scroll down (page) |
| `b` | Scroll up |
| `PgUp` | Scroll up (page) |

## Note Actions

- `Enter` - Open the selected note
- `e` - Edit current note
- `n` - Create a new note
- `d` - Delete current note
- `/` or `s` - Search notes

## Edit Mode

When editing a note (press `e`):

| Key | Action |
|-----|--------|
| `j` or `↓` | Move cursor down |
| `k` or `↑` | Move cursor up |
| `i` | Insert new line below cursor |
| `x` | Delete current line |
| `o` | Edit line (placeholder) |
| `s` | Save changes |
| `q` or `ESC` | Exit edit mode without saving |

## General

- `?` - Toggle help menu
- `q` - Quit Grimoire

---

**Note**: The editor is simplified in this version. For full editing capabilities, you can edit the markdown files directly with your favorite text editor!

**Pro Tip**: Most navigation commands are inspired by Vim for efficiency!
