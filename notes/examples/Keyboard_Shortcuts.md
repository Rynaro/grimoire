# Keyboard Shortcuts

This note contains all the keyboard shortcuts available in Grimoire.

## Navigation

| Key | Action |
|-----|--------|
| `j` or `↓` | Move selection down |
| `k` or `↑` | Move selection up |
| `h` or `←` | Switch to folders |
| `l` or `→` | Switch to notes |
| `Space` | Scroll down |
| `b` | Scroll up |

## Note Actions

- `Enter` - Open the selected note
- `e` - Edit current note
- `n` - Create a new note
- `d` - Delete current note
- `/` - Search notes

## Edit Mode

When editing a note:

- `j/k` - Navigate between lines
- `i` - Insert new line below
- `x` - Delete current line
- `s` - Save changes
- `q` or `ESC` - Exit without saving

## General

- `?` - Toggle help menu
- `q` - Quit Grimoire
